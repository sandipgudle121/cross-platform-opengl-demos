# OpenGL and OpenGL ES Projects

A collection of graphics programming exercises and demos organized by platform. The projects explore the progression from creating a window and drawing basic shapes to lighting, textures, shader techniques, and framebuffer effects.

## Platforms

- **Windows** — desktop OpenGL examples
- **Linux X11** — desktop OpenGL examples
- **Android** — OpenGL ES applications
- **WebGL** — browser-based graphics demos
- **macOS** — OpenGL examples
- **iOS** — OpenGL examples

## Topics

Depending on the platform, the collection includes examples of:

- Window creation, input events, and fullscreen mode
- Orthographic and perspective projection
- 2D and 3D shapes, color, and rotation
- Textures and texture mapping
- Diffuse, per-vertex, and per-fragment lighting, including materials
- Matrix stack transformations and hierarchical scenes
- Framebuffers and render-to-texture
- Tessellation and geometry shaders
- Interleaved vertex data and indexed drawing

## Repository layout

Each top-level directory represents a platform. Inside it, numbered directories group related exercises and generally show their learning progression. Implementations and setup vary by platform; use the project files and instructions in each demo directory.

The WebGL examples include a `Canvas.html` entry point in their demo folders. Open one in a browser to explore the corresponding demo.
